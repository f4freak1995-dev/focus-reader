PRIVACY

阅读留在本机。

更新日期：2026 年 10 月 6 日。本说明针对本网站及当前本地版本；未来同步功能需另行披露数据范围和服务。

本网站

网站不含广告、第三方分析脚本、远程字体、登录表单或书籍上传功能。深浅外观和手动选择的语言会保存在浏览器 localStorage 中，不发送给项目维护者。自动选择语言依据浏览器偏好，不查询地理位置；播放示意只在浏览器内运行。

如通过 GitHub Pages 托管，GitHub 会按其政策记录包括访客 IP 在内的访问信息，详见 GitHub Pages 说明及 GitHub 隐私声明。外部链接、发布下载和 GitHub 反馈也受对应服务政策约束。

当前桌面应用

书籍原件、解析正文、阅读状态和个人标注存于本地书库。当前无账号或云同步，不会因为访问本网站就上传你的书。自行把书库放在云盘中会受云盘服务影响；运行中的 SQLite 数据库不适合直接作为跨设备同步方案。

反馈和公开信息

公开反馈只需提供复现步骤和必要的脱敏日志。不要提交未经允许的书籍全文、私人笔记、字体、密码或完整个人数据库。联系入口为 维护账号。
