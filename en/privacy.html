PRIVACY

Your reading stays local.

Updated October 6, 2026. This notice covers this website and the current local builds; any future sync feature requires separate disclosure of data handling and services.

This website

The website has no ads, third-party analytics, remote fonts, login forms or book uploads. Appearance and manually selected language are stored in your browser's localStorage and are not sent to the maintainer. Automatic language selection uses browser preferences, not your location. Reading demos run only in your browser.

When hosted on GitHub Pages, GitHub records visit information, including visitor IP addresses, under its policies. See GitHub Pages documentation and GitHub's privacy statement. External links, release downloads and GitHub feedback are also subject to the relevant service policies.

The current desktop app

Original books, extracted text, reading state and personal annotations are stored in a local library. There is no account or cloud sync. Visiting this website does not upload your books. If you put your library in a cloud drive, that service may affect it; a live SQLite database is not suitable as a direct cross-device sync mechanism.

Feedback and public information

Public feedback should contain only reproduction steps and necessary redacted logs. Do not submit unauthorized full books, private notes, fonts, passwords or a complete personal database. Contact the maintainer.
